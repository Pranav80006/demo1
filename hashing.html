What is Hashing in Data Structures?

Definition

Hashing is a technique used in data structures to store and retrieve data efficiently. It involves mapping data of arbitrary size to fixed-size values using a mathematical function called a hash function. The resulting value is called a hash code or hash value, which is used as an index to store the data in a data structure called a hash table.

Key Concept: Hashing transforms data into a fixed-size integer value that serves as an address for storing and retrieving the data in constant time O(1) on average.

Components of Hashing

1. Hash Function

A hash function takes an input (key) and returns a fixed-size integer (hash value).

Properties of a good hash function:

  • Deterministic: Same input always produces the same output
  • Uniform Distribution: Hash values should be evenly distributed
  • Fast Computation: Should be quick to compute
  • Minimize Collisions: Different inputs should produce different outputs

2. Hash Table

A hash table is a data structure that stores key-value pairs. It uses the hash value as an index to determine where the data should be stored in an array.

3. Collision Handling

A collision occurs when two different keys produce the same hash value. Common collision resolution techniques include:

  • Chaining: Store multiple elements at the same index using linked lists
  • Open Addressing: Find another empty slot using probing (linear, quadratic, or double hashing)

Example: Simple Hash Function

// Simple hash function for strings
function hashFunction(key, tableSize) {
    let hash = 0;
    for (let i = 0; i < key.length; i++) {
        hash += key.charCodeAt(i);
    }
    return hash % tableSize;
}

// Example usage
let tableSize = 10;
console.log(hashFunction("apple", tableSize));  // Returns index 0-9
console.log(hashFunction("banana", tableSize)); // Returns index 0-9

Time Complexity

  • Average Case:
    • Search: O(1)
    • Insert: O(1)
    • Delete: O(1)
  • Worst Case: O(n) - when all keys hash to the same index

Applications of Hashing

  • Databases: Fast data retrieval using hash indexes
  • Caching: Quick lookup of cached data
  • Password Storage: Storing hashed passwords for security
  • Hash Tables/Maps: Implementing dictionaries and sets
  • Checksums: Data integrity verification
  • Cryptography: Digital signatures and message authentication
  • Load Balancing: Distributing requests across servers

Common Hash Table Implementations

  • JavaScript: Map, Set, Object (uses hashing internally)
  • Python: dict, set
  • Java: HashMap, HashSet, Hashtable
  • C++: unordered_map, unordered_set

Advantages

  • Fast data access (constant time on average)
  • Efficient for large datasets
  • Simple implementation
  • Dynamic resizing possible

Disadvantages

  • Collisions can degrade performance
  • No ordering of elements
  • Requires good hash function design
  • Extra memory for storing hash table structure

Conclusion

Hashing is a fundamental technique in computer science that enables efficient data storage and retrieval. Understanding hashing is crucial for designing high-performance applications and solving algorithmic problems that require fast lookups.
